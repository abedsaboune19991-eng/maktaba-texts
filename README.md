# فهرس نصوص المكتبة الإسلامية

يحوي هذا المستودع نصوص كتب «المكتبة الإسلامية» صفحةً صفحة، ليبحث فيها تطبيق المكتبة داخل الكتب.

- `texts/` نص كل كتاب مضغوطًا، والصفحات مفصولة بالرمز `\f`.
- `manifest.json` قائمة الكتب المفهرسة وعدد صفحاتها وطريقة استخراج نصها (`text` من طبقة النص، و`ocr` بالتعرّف الضوئي، و`mixed` خليط منهما).
- `library.json` كتب إضافية تظهر في التطبيق إلى جانب كتب الموقع.
- `library/` ملفات هذه الكتب الإضافية وأغلفتها.

يعمل GitHub Actions أسبوعيًّا، وعند تعديل `library.json`، فيفهرس الكتب الجديدة وحدها.
